# 🚀 Guía Rápida - Dashboard Parroquial

## ⚡ Inicio Rápido

### 1️⃣ Abrir el Dashboard

**Doble clic en:** `DASHBOARD_V3.bat`

El dashboard se abrirá automáticamente en tu navegador.

---

## 📱 Acceso desde Celular

### Paso a Paso:

1. **Ejecuta** `DASHBOARD_V3.bat` en tu computadora
2. **Espera** a que aparezca la ventana negra con texto
3. **Busca** la línea que dice **"Network URL:"**
   ```
   Network URL: http://192.168.1.5:8503
   ```
4. **Copia** esa dirección completa
5. **Abre** el navegador en tu celular
6. **Pega** la dirección y presiona Enter

### ⚠️ Importante:
- Tu celular y computadora deben estar en la **misma red WiFi**
- La dirección puede cambiar, siempre copia la que aparece en pantalla
- Ejemplo de dirección: `http://192.168.1.5:8503`

## 🔧 Solución de Problemas

### El dashboard no se ve bien (texto blanco)
✅ **SOLUCIONADO** - La nueva versión v3.0 tiene contraste correcto

### No puedo ver la Network URL
- Espera unos segundos después de ejecutar el .bat
- Busca una línea que empiece con "Network URL:"
- Si no aparece, verifica tu conexión WiFi

### El celular no se conecta
1. Verifica que ambos dispositivos estén en la misma WiFi
2. Copia la dirección exacta (incluyendo http:// y :8503)
3. Desactiva temporalmente el firewall si es necesario

### El informe Word no se abre
- Verifica que tengas Microsoft Word instalado
- Busca manualmente en la carpeta `informes\`
